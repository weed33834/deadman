## 0. 阅读说明与符号约定

| 符号 | 含义 |
|---|---|
| `[P0/P1/P2]` | 优先级（P0 首版必须，P1 首版后，P2 延后） |
| `角色@元素` | 该元素对某角色的可见/可操作等级 |
| `🔒` | 权限受限，见 §3 权限矩阵 |
| `🗂` | 数据来源（DB 表 / 文件 store / 平台库 / 机构库） |

统一术语：
- **机构** = 租户；**成员** = 机构员工；**客户** = 机构服务的对象（C 端被服务人）；**案件** = 围绕一个客户的一次服务流程；**材料包** = 可打印的办事材料/信函合集。

## 1. 产品定位（已确认）

**骨架 = To B 多租户平台**（殡葬/保险/遗产机构租用，管理客户、案件、成员、知识、合规）。
**上层能力 = C 端对话引导**（客户/家属通过客户门户被服务，数据归属机构）。
首版锁定**殡葬服务商**样板行业，其余行业走模板。

非目标（不做）：C 端公域产品、跨机构数据交换、行业分叉代码、通用智能体平台对外卖点、实时 IM。

## 2. 用户角色与页面可见性

| 角色 | 层级 | 进入路径 | 可访问页面 |
|---|---|---|---|
| `platform_admin` | 平台 | 运营后台 `/admin` | 机构管理（全部）+ 平台知识库维护 |
| `org_admin` | 机构 | 工作台 `/org` | 工作台全部页 + 设置 + 审计 |
| `case_manager` | 机构 | 工作台 `/org` | 仪表盘/客户/案件/知识库(机构可编辑)/成员只读 |
| `consultant` | 机构 | 工作台 `/org` | 仪表盘/客户/案件（只读为主）/知识库只读 |
| `viewer` | 机构 | 工作台 `/org` | 仪表盘/客户/案件/知识库（全只读） |
| 客户/家属 | 客户侧 | 客户门户链接（不登录工作台） | 对话 / 材料提交 / 进度 |

> 规则：**客户永不进入机构工作台**。成员按 §3 矩阵控制页面与按钮级权限。

## 5. 全局设计规范

- **布局**：桌面优先（1920/1440 断点），机构成员主要桌面办公。左 240px 侧边栏 + 内容区。
- **组件体系**：沿用 `admin.html` 技术栈（原生 JS + fetch + 统一 CSS），不引入前端框架。
- **数据状态四态**：加载（骨架屏）→ 成功 → 空态（带引导 CTA）→ 错误（可重试）。每个列表页必须实现空态。
- **权限不足态**：整页无权限 → 显示"无权限访问"；元素级 → 隐藏或禁用并 tooltip 说明。
- **到期/冻结态**：机构 `status=suspended|expired` → 顶部常驻红色横幅 + 全部写操作禁用，仅审计/导出/设置可见（只读）。
- **时间/金额格式**：遵循机构 `i18n/locale`；日期统一 `YYYY-MM-DD HH:mm`，近 7 天显示相对时间。
- **操作反馈**：所有写操作成功 toast「已保存」；破坏性操作二次确认弹窗（删除/禁用/过期归档）。

## 6. 机构工作台逐页详设

### 6.1 登录与机构切换页 `[P0]`

**入口**：未登录访问 `/org` → 跳登录页。

| 元素 | 说明 |
|---|---|
| 品牌区 | 左侧：deadman logo + 「机构工作台」标题 + 主/辅宣传语 |
| 登录表单 | 邮箱 + 密码；「忘记密码」→ 发重置邮件（auth/password_reset） |
| 登录方式 | 邮箱密码 + 可选 OAuth（P2） |
| 多机构下拉 | 该用户若属多机构，登录后出现「选择机构」页：机构卡片列表（名称/角色徽标/状态）；单机构直接进入 |
| 错误态 | 密码错误 / 账号禁用（membership.status=disabled）/ 机构到期 → 各自明确文案 |
| 行为 | 登录成功 → 写 `membership.last_login` 审计；跳转默认页（机构工作台） |

**验收**：多机构用户能切换；被禁用成员登录被拒并提示联系机构管理员；到期机构写操作被禁。

### 6.4 客户详情页 `[P0]` `🗂 customers + cases + materials + dialogue`

**入口**：客户列表点击。**权限**：consultant/viewer 只读；case_manager+ 可编辑。

**页头**：客户名 + 状态徽标 + 年龄/性别/省份摘要 + 操作（编辑 / 生成客户门户链接🔒 / 删除🔒）。

**Tab 结构**：

| Tab | 内容 | 关键点 |
|---|---|---|
| 档案 | 基本信息：姓名/性别/出生/证件/电话/地址/关系人列表/阶段/标签/自定义字段（按行业模板） | 关系人支持多个；PII 落盘前掩码 |
| 案件 | 该客户全部案件列表（状态机徽标/办理员/创建时间）→ 点入案件详情 | 空态引导「为这位客户新建案件」 |
| 材料包 | 已生成材料包列表（名称/版本/生成时间/下载/打印） | 由案件内生成后聚合展示 |
| 对话记录 | 客户门户对话历史（摘要式，PII 掩码） | 只读 |
| 审计 | 该客户相关的操作日志（谁/何时/做了什么） | org_admin 可导出 |

**自定义字段**：按机构 `industry_template` 渲染（殡葬：治丧日期/殡仪馆/墓地；保险：保单号/受益人），运行期可增补（机构库）。

**验收**：非本机构成员访问他人客户 → 403；PII 掩码规则生效；审计可追溯到每次编辑。

## 7. 平台运营后台逐页详设（platform_admin）`[P1]`

> 入口 `/admin`，独立于机构工作台；仅 `platform_admin` 可访问。

### 7.1 机构总览页

KPI：机构总数 / 活跃 / 试用中 / 到期预警数。全局检索框（机构名/域名/ID）。

### 7.2 机构列表页

| 元素 | 说明 |
|---|---|
| 表格列 | 机构名 / 行业模板 / plan / 状态 / 成员数 / 客户数 / 到期时间 / 创建时间 / 操作 |
| 操作 | 查看详情 / 封禁·解封 / 改 plan / 生成授权码 |
| 筛选 | 状态 / 行业 / plan / 到期时间 |

### 7.3 机构详情页

机构资料 + 用量（成员/客户/案件/storage/token）+ 成员列表（只读）+ 审计（该机构全量）+ 操作：
- 手动延期 / 授权码 / 数据导出（合规兜底）/ 强制注销。

### 7.4 套餐与许可证页

套餐定义（free/pro/enterprise 的配额与功能白名单）+ 授权码生成（instance_id/user_limit/features/expires）+ 试用状态管理。
授权码格式：`license = {instance_id, org_limit, user_limit, features, expires_at}`，HMAC-SHA256 签名（技术文档 §7）。

### 7.5 平台审计页

全平台操作日志 + 越权拦截告警（技术文档 §7.4），支持按机构/操作者/类型筛选与导出。

## 8. 客户门户逐页详设（客户/家属侧）`[P1]`

> 客户不登录工作台。机构生成「客户门户链接」（绑定客户 ID + 短期 token），客户点击进入单页应用。

### 8.1 门户首页（对话为主）

| 区块 | 说明 |
|---|---|
| 欢迎区 | 机构品牌（白标）+ 客户姓名称呼 + 当前阶段提示 |
| 对话窗 | 核心交互：客户打字提问（政策/流程/材料），AI 引导员回答（带来源四要素）|
| 快捷入口 | 「提交材料」「查看进度」「联系办理员」卡片 |

### 8.2 材料提交页

| 元素 | 说明 |
|---|---|
| 待补清单 | 机构端 `case_manager` 挂出的待补材料项（名称/说明/必填）|
| 上传区 | 拖拽/选择文件；图片自动 OCR 预提取（doc_extract）；PII 校验与掩码 |
| 已提交列表 | 文件列表 + 状态（已收/待核/被打回）|
| 提交动作 | 一键提交 → 通知机构端（notification）|

### 8.3 进度查看页

只读展示该客户案件的当前状态机步骤 + 时间线（去 PII 摘要）。

**验收**：客户只能访问自己的案件；链接 token 过期需重新获取；提交材料实时通知机构端；不暴露其他客户/机构内部信息。

## 9. 机构入驻与引导流程 `[P0]`

```
注册（平台）→ 创建机构（选行业模板 funeral + plan）→ 成为 org_admin
→ 引导页：邀请 3 名成员 → 建首位客户档案 → 建首案件 → 生成首个材料包
→ 完成引导（对应成功指标「入驻→首客户 <1 天」）
```

**引导页元素**：四步进度条 + 每步内联表单 + 跳过入口（可后补）+ 完成庆祝态。
**引导状态持久化**：`organizations.onboarding_step`，跳过或完成即不再显示。

## 10. 验收口径（页面级，对应里程碑 M1–M6）

| 里程碑 | 页面级验收 |
|---|---|
| M1 组织地基 | 注册→建机构→邀请 3 成员→分配角色成功；机构 A/B 数据互不可见 |
| M2 数据隔离 | 两机构同时办案，交叉访问全部 403；审计可追溯 |
| M3 客户+案件 | 客户列表→详情→新建案件→推进状态→生成材料包→归档，全程可走通 |
| M4 工作台 | 仪表盘实时；办理员 30 分钟不培训会办案（引导页兜底）|
| M5 交付 | 私有化镜像一键启动 + 授权码生效 + 数据导出可用 |
| M6 清理 | 对外单入口/单品牌/单叙事；C 端仅保留为客户门户一环 |
