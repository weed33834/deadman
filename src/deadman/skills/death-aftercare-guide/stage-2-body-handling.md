# 阶段二：遗体处理与殡葬

> 本阶段在整体流程中的位置：死亡证明取得后紧接的事项，涉及时限较紧，需尽快安排。

## 目标

妥善安置遗体，完成殡葬事宜（火化、土葬或其他方式），领取骨灰或完成安葬，避免超期存放产生额外费用或合规风险。

## 建议时限

遗体接运建议在死亡后尽快联系（通常 24 小时内）；殡葬处置一般需在死亡后数日至两周内完成，各地不同。具体时限见地域知识库（请以当地最新政策为准，建议电话确认）。

## 通用流程

1. **根据死亡地点，确定遗体安置去向**

   | 死亡地点 | 默认去向 | 说明 |
   |---|---|---|
   | 医院内死亡 | 医院太平间/殡仪馆暂存 | 医院一般提供短期暂存（通常数天，超期可能收费，请以当地最新政策为准）；之后由家属联系殡仪馆接运 |
   | 家中 / 公共场所死亡 | 直接联系殡仪馆派车接运 | 凭死亡证明（家中自然死亡需医疗机构已出具的证明；非正常死亡需执法部门放行通知）联系殡仪馆 |
   | 家中暂存 | 仅极短期，文化/宗教原因 | 多数地区规定死亡后需及时接运，家中长期存放可能违反当地殡葬规定，不建议 |

   > 不要找无资质的"黑殡仪"或路边中介接运，务必联系正规殡仪馆（见下文"常见坑"）。

2. **选择殡仪馆/殡葬服务提供商**

   殡仪馆一般可在以下地点中**任选其一**办理（具体以当地规定为准）：
   - 逝者户籍/登记地
   - 死亡发生地
   - 逝者常住地

   > 三地政策略有差异，部分地方对受理地有限制。建议先电话咨询目标殡仪馆是否接收，再决定（请以当地最新政策为准）。

3. **确认殡葬服务内容与费用**

   正规殡仪馆的基本服务项目通常包括：
   - 遗体接运（车辆、担架）
   - 冷藏存放
   - 整容化妆
   - 告别厅租赁
   - 火化或土葬安排
   - 骨灰寄存

   费用分两类：
   - **基本服务**：政府定价、政府指导价或受监管价格（接运、冷藏、火化等），价格公开透明
   - **延伸服务**：市场价（花圈、寿衣/殓服、告别厅升级、礼仪服务等），自愿选择

   > 基本费用可咨询当地殡葬主管部门核实政府定价标准。查询电话见地域知识库。

4. **选择安葬/处置方式**

   | 方式 | 适用情形 | 说明 |
   |---|---|---|
   | 火化 | 多数地区主流或强制 | 火化后骨灰可寄存、安葬、海葬、树葬等 |
   | 土葬 | 部分地区允许（宗教/文化传统、特定地区） | 需符合当地规定，部分需额外许可 |
   | 生态葬（海葬、树葬、草坪葬等） | 自愿选择 | 多地有补贴政策，可咨询当地主管部门 |
   | 其他 | 宗教/民族特殊安排 | 需符合当地法律 |

   > 各地对火化/土葬的政策差异大，具体见地域知识库，务必电话确认当地规定。

5. **办理处置，领取骨灰与处置证明**

   处置时需出示死亡证明原件，殡仪馆查验后留存副本。处置完成后殡仪馆出具**处置证明/火化证明**，凭此证明可办理：
   - 身份/户籍注销（部分地区需处置证明）
   - 丧葬补助、抚恤金申领
   - 殡葬补贴领取

   骨灰可选择寄存（殡仪馆或公墓骨灰堂）、安葬（公墓）、生态葬等。

6. **（如逝者生前登记捐献）联系捐献机构**

   若逝者生前登记了器官或遗体捐献，需立即联系当地捐献登记机构或接收单位，由其按捐献流程处置。详见 `special-cases.md`。

## 通用注意事项（常见坑）

- **处置时限紧**：多数地区对遗体存放和处置有时限要求，逾期可能产生额外冷藏费用或合规问题（请以当地最新政策为准）。
- **医院太平间与殡仪馆冷藏的区别**：医院太平间通常是短期暂存，殡仪馆冷藏是正式存放。医院太平间超期会按天收费，且费用可能高于殡仪馆。建议尽早联系殡仪馆接运。
- **"黑殡仪"中介乱收费**：部分社会中介冒充"官方殡仪馆"或"医院指定殡葬"，收取高额服务费，甚至强推天价殓服、骨灰盒。识别与规避方法：
  - 正规殡仪馆均有主管部门核发的经营资质
  - **通过当地官方渠道（政务热线、殡葬主管部门）核实**殡仪馆是否正规
  - 正规殡仪馆接运车有明显标识
  - 不要相信主动上门或医院门口搭讪的"殡葬服务"
- **签订服务合同前看清明细**：正规殡仪馆会出具价目明细单，基本服务与延伸服务分别列明。拒绝口头报价、无凭据收费。
- **骨灰寄存到期未续**：殡仪馆或骨灰堂寄存一般按年收费，到期未续且未领走的，机构可能按无主骨灰集中处理。建议设个提醒，按时续费或择期安葬。
- **宗教/文化习俗**：不同文化、宗教的殡葬习俗应受尊重，但仍需符合当地法律。具体政策咨询当地主管部门。
- **殡葬补贴/丧葬费**：各地待遇不同，一般通过社保或民政渠道申领，需凭处置证明、死亡证明、办理人材料。详见 `stage-8-social-benefits.md`（请以当地最新政策为准）。
- **器官/遗体捐献的时效**：器官捐献需在死亡后极短时间内（一般数小时内）联系登记机构，超过时效无法用于移植；遗体捐献用于医学教育，时限相对宽松但仍需尽快联系。

## 完成后的下一步

处置完成并领取处置证明后，可并行推进：
- 身份/户籍注销（部分地区需凭处置证明，见 `stage-3-household-cancel.md`）
- 社保/福利结算、丧葬补助/抚恤金申领（见 `stage-8-social-benefits.md`）
- 银行存款、房产、车辆等财产处理（见 stage-5、stage-6、stage-7）

> 这件事我没办法替你做——联系殡仪馆、签订殡葬服务合同、办理处置都必须家属现场办理，我也无法代查殡仪馆资质。我能做的是告诉你流程、辨别正规机构的方法、费用参考、避坑提示。这种时候容易被中介乘虚而入，多打个电话核实就少踩一个坑。
