# 阶段一：死亡证明办理

> 本阶段在整体流程中的位置：逝者身后事的第一步，几乎所有后续事项（殡葬、身份注销、继承、保险理赔、银行取款）的前提。

## 目标

取得当地合法有效的**死亡证明**（由有权机构签发），作为后续一切事务的法定凭证。

## 建议时限

死亡发生后尽快办理，通常建议在数天内完成。具体法定时限见地域知识库（请以当地最新政策为准，建议电话确认）。

## 通用流程

1. **判断死亡地点与死因，确定签发主体**

   死亡证明的签发主体因死亡地点和死因不同而不同。通用分类如下（具体机构名称见地域知识库）：

   | 死亡地点 / 情形 | 签发主体（通用） | 关键说明 |
   |---|---|---|
   | 医院内死亡 | 涉事医院 / 主治医生 | 住院或急诊抢救无效死亡，由主治医生填写，医院盖章出具 |
   | 家中自然死亡（有明确病史或老年衰竭） | 当地医疗机构 / 社区医生 / 全科医生 | 通常需有逝者近期就诊记录或慢性病档案；医生上门或到场核实后出具 |
   | 非正常死亡（意外、自杀、他杀、不明原因） | 必须先联系当地执法部门，由法医 / 验尸官 / 法医办公室签发 | 保护现场，不要擅自移动遗体；由执法部门出具死亡证明或法医鉴定文书 |
   | 养老机构 / 护理机构死亡 | 视死因而定 | 自然死亡走医疗机构；突发或原因不明走执法部门；机构一般会协助家属办理 |

   > 如果不确定属于哪种情况，先拨打当地急救电话或报警电话（号码见地域知识库）说明情况，由专业人员判断。

2. **电话联系签发主体，确认所需材料与办理时间**

   不要直接冲过去——不同机构、不同地区要求略有差异。先打电话问清：
   - 需要带哪些材料
   - 办公时间（部分机构仅工作日特定时段办理）
   - 是否需要家属本人到场

   查询电话可通过当地官方查号台、政务热线、官方网站查询（具体号码见地域知识库）。**不要轻信来路不明的"代办"广告**。

3. **携带材料现场办理**

   由家属（一般为近亲属）带齐材料到签发主体处办理。医生或有关人员核实后出具死亡证明。

4. **立即制作多份经认证的副本备用**

   原件通常只有一份，必须妥善保管。后续殡葬、身份注销、继承、保险、银行等几乎每一项都要用到。建议：
   - 当场申请多份**核证副本/ certified copies**（数量依当地可申请份数，建议 8-10 份以上）
   - 部分机构办理时可在副本上加盖认证章
   - 原件随身保管，不要交给任何单一机构长期留存

5. **（如当地支持）尝试线上申报**

   部分国家/地区已开通线上申请电子死亡证明或预约线下办理。可通过当地政务平台查询是否支持（请以当地最新政策为准）。

## 通用注意事项（常见坑）

- **原件只有一份，遗失补办非常麻烦**：死亡证明原件是后续一切事项的"通行证"，丢失后需回原签发机构补开，部分机构补办周期长、手续繁琐。务必申请多份核证副本，原件单独保管。
- **核证副本比普通复印件更有效力**：很多机构（银行、保险、不动产登记）要求死亡证明为**核证副本/认证副本**而非自行复印的普通复印件，办理时一次性多申请几份。
- **家中自然死亡但近期没有病历**：当地医疗机构可能拒开死亡证明。尽量提供过往就诊记录、慢性病档案、护理机构记录、家属书面陈述等。若仍被拒，可咨询当地卫生主管部门或政务热线（请以当地最新政策为准）。
- **非正常死亡务必先联系执法部门**：不要擅自处理遗体或清理现场，可能影响法医鉴定和后续责任认定、理赔。
- **异地/跨地区死亡的死亡证明**：原则上由死亡地机构签发，但部分地区要求回常居地换开或公证，详细处理见 `special-cases.md`（请以当地最新政策为准）。
- **电子死亡证明的效力**：已推行电子证明的地区，电子件与纸质件效力以当地规定为准；跨地区/跨国使用时部分机构可能仍要求纸质原件或认证副本，建议两份都备着。
- **不要把原件交给殡仪馆或中介**：殡葬时只需查验原件、留存副本，不要让原件离开你的视线。
- **家中死亡先别急着挪动**：在医生或有关人员上门核实前，保持遗体原状，便于死因判定。

## 完成后的下一步

拿到死亡证明后，即可并行推进：
- 遗体处理与殡葬安排（见 `stage-2-body-handling.md`）
- 身份/户籍注销准备（见 `stage-3-household-cancel.md`）
- 通知逝者雇主、保险公司、社保/福利机构

> 这件事我没办法替你做——死亡证明必须家属现场办理，我也无法代查病历或代签。我能做的是告诉你流程、材料清单、找谁办、怎么避免踩坑。急不来，按你的节奏。
