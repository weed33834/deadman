# 阶段三：身份/户籍注销

> 本阶段在整体流程中的位置：殡葬完成后需办理的法定事项，影响后续多项事务。是否实施户籍/身份登记制度因国家而异，本阶段适用于有相关登记制度的地区。

## 目标

依法注销/更新逝者的身份登记（户籍、国民身份登记、选民登记等），完成相关证件的作废或更新，避免影响家庭其他成员事务、防止身份信息被冒用。

> 说明：并非所有国家都有户籍制度。无户籍制度的国家，本阶段主要指：通知身份登记机构更新死亡记录、注销身份证件/护照/驾照、更新选民登记等。具体适用事项见地域知识库。

## 建议时限

一般要求在死亡后一定期限内办理（如 30 天内），部分地区更短。具体法定时限见地域知识库（请以当地最新政策为准，建议电话确认）。

## 通用流程

1. **先盘点：注销前必须确认的事项**

   注销后，相关证件原件可能被收回或作废，再凭这些证件办理的事项会变复杂。**注销前请逐一确认以下事项是否已办妥或已准备替代材料**：
   - 银行存款查询/提取（部分银行要求身份证件证明身份/亲属关系）
   - 不动产（房产）过户或继承认证
   - 车辆过户
   - 社保/福利结算、住房储蓄账户提取（部分地方需身份证件）
   - 商业保险理赔
   - 股票/基金账户继承

   > 如果上述事项尚未办理，建议先咨询相关机构是否需要逝者身份证件原件，再决定注销时机。不确定的话，**先打当地政务热线或对应机构客服问一句**，比事后补救省事得多。

2. **确认办理地点**

   身份/户籍注销一般在**逝者登记地的相关登记机构**办理：
   - 登记地与常居地一致的：直接到登记地机构办理
   - 登记地与常居地不一致的：原则上必须回登记地办理
   - 部分地区已开通跨地区通办，可通过当地政务平台查询是否支持（请以当地最新政策为准）

3. **携带材料到登记机构现场办理**

   通用办理流程：
   1. 家属（一般为近亲属）带齐材料到登记机构窗口
   2. 工作人员核验材料
   3. **收缴/作废逝者身份证件**（如身份证、户口本注销页盖章等，各地做法不同）
   4. 出具**注销证明/死亡登记证明**

4. **妥善保管注销证明**

   后续社保、银行、不动产等业务办理时，常需提供注销证明。建议申请多份核证副本备用。

5. **（特殊身份人员）通知相关单位**

   - 退役军人/现役军人：通知当地退伍军人事务部门
   - 公务员/公共部门人员：通知原单位人事部门
   - 涉密岗位人员：按原单位要求办理脱密后续事项
   - 持有特殊证照人员（枪证、专业执照等）：按规注销

## 通用注意事项（常见坑）

- **注销前忘了办其他事**：这是最常见的坑。身份证件注销后，银行、不动产、社保等需要证件证明亲属关系的事项会变得麻烦，可能需要额外办亲属关系证明。**强烈建议注销前先把需要证件的事项盘点清楚**。
- **身份证件提前复印多份**：办理注销时会作废原件，但很多后续事项（如银行、保险）可能还需要逝者身份证件复印件。建议在注销前复印/扫描 5-8 份备用。
- **登记本上还有其他家庭成员**：注销时一般只在逝者那一页盖章或更新记录，不会影响其他家庭成员的登记。但部分机构做法不同，办理时确认清楚。
- **异地注销被推诿**：必须回登记地办理的情况下，部分家属因距离远希望异地办，可能被推诿。可询问是否支持跨地区通办；如遇推诿可向当地政务热线投诉，建议办理过程留存记录。
- **逝者身份证件不要急于销毁**：在正式作废前，原件仍在某些场景可用（如查询银行账户、社保账户）。但**不要用于任何欺诈性事务**，仅用于查询逝者信息。
- **特殊身份人员**：除身份注销外，还需通知原单位或退伍军人事务部门，否则可能影响抚恤金、遗属待遇等申领。
- **不注销的后果**：逾期不注销属于违规，可能影响家庭其他成员办理相关业务，且逝者身份证件若被冒用家属可能需担责。务必按时办理。
- **无户籍制度的国家**：主要任务是通知死亡登记机构更新记录、注销护照/驾照/选民登记、退还医保卡等福利证件，流程相对简单，但仍需逐项办理避免身份盗用。

## 完成后的下一步

身份/户籍注销完成后，可推进：
- 社保/福利结算、丧葬补助/抚恤金申领（凭注销证明 + 处置证明，见 `stage-8-social-benefits.md`）
- 住房储蓄账户/公积金提取（若当地适用，见 `stage-8-social-benefits.md`）
- 银行存款、房产、车辆等财产继承（见 stage-5、stage-6、stage-7）
