# checklists.md（全流程清单合集）

> 本文件为逝者身后事全流程清单合集，包括按时间分阶段的总清单、材料总清单、机构联系清单、各地区差异提示、常见 10 大坑。用于整体规划和随时勾选。所有时限、金额、政策以当地最新规定为准，具体从地域知识库加载。

---

## 一、总清单（按时间）

### 即刻（0-24 小时）

- [ ] **判断死因**：自然死亡 / 非正常死亡。非正常死亡立即联系当地执法部门（报警电话见地域知识库），保护现场。
- [ ] **取得死亡证明**：医院内死亡由医院开具；家中自然死亡由当地医疗机构开具；非正常死亡由法医/验尸官开具。
- [ ] **遗体安置**：联系殡仪馆接运，或暂时安置（家中/医院太平间，视当地规定）。
- [ ] **通知近亲属**：告知至亲，必要时通知雇主。
- [ ] **保留逝者手机和证件**：手机不要过早销号（验证码要用），身份证件、医保卡、银行卡收好。

### 短期（1-7 天）

- [ ] **殡葬安排**：选定殡仪馆，确定处置方式（火化/土葬/其他，遵循宗教文化习俗及当地政策）。
- [ ] **身份/户籍注销**：凭死亡证明到登记地相关机构办理（时限各地不同，请以当地最新政策为准）。
- [ ] **通知相关单位**：雇主、保险公司、社保/福利机构。
- [ ] **收集逝者证件材料**：身份证件、婚姻证明、产权证、银行卡、存折、保单、合同。
- [ ] **多份死亡证明核证副本**：建议申请 8-10 份以上，多处使用。
- [ ] **查找遗嘱**：检查逝者遗物、保险箱、律师、公证处是否有遗嘱。
- [ ] **初步清点遗产与债务**：列清单，包括房产、存款、股权、债权、债务。

### 中期（约 30 天内）

- [ ] **数字账号处理**：各类 App/平台走逝者通道注销或继承（参见 `stage-4-digital-accounts.md`）。
- [ ] **银行存款查询与提取**：若当地有小额简化程序（门槛见地域知识库），门槛以下可走简化程序；超过门槛需继承认证/公证（参见 `stage-5-financial-assets.md`）。
- [ ] **社保/福利结算**：养老金/退休金停发、个人账户余额继承、丧葬补助、抚恤金申领（参见 `stage-8-social-benefits.md`）。
- [ ] **住房储蓄账户/公积金提取**（若当地适用）：到开户管理机构办理。
- [ ] **医保个人账户余额继承**（若当地有）：医保卡停用，余额依法继承。
- [ ] **商业保险理赔**：联系保险公司，提交理赔材料。
- [ ] **企业年金 / 职业年金 / 私人养老金结算**（若当地有）：联系原单位人事或年金管理机构。
- [ ] **公告债权人**（建议）：通过当地规定渠道公告，降低后续被诉风险。
- [ ] **工伤认定**（如因工死亡）：联系社保/劳工部门和用人单位。

### 长期（1-6 个月）

- [ ] **遗产继承认证/遗嘱认证**：多名继承人或大额遗产常需办理（参见 `stage-7-estate-inheritance.md`）。
- [ ] **房产过户**：继承认证 → 不动产登记机构（参见 `stage-6-real-estate.md`）。
- [ ] **车辆过户**：到车辆登记机构办理。
- [ ] **股票/基金/理财账户继承**：联系券商，凭继承文书办理。
- [ ] **公司股权处理**（若有）：涉及章程/股东协议、其他股东优先购买权等，建议咨询律师。
- [ ] **债权债务清理**：催收债权，清偿债务，应对催收（参见 `stage-9-debts-obligations.md`）。
- [ ] **税务清缴**：个税、房产税、遗产税（若当地有）、企业税费等。
- [ ] **特殊情形处理**（如适用）：异地、海外、纠纷、未成年子女监护等（参见 `special-cases.md`）。

## 二、材料总清单（通用模板）

> 建议集中存放，办理不同事项时按需取用。所有原件妥善保管，使用核证副本/复印件优先。具体所需材料以当地机构要求为准（见地域知识库）。

### 逝者相关
- [ ] **死亡证明**（核证副本，建议 8-10 份以上）
- [ ] **逝者身份证件**（原件 + 复印件，注销前多复印几份）
- [ ] **逝者身份/户籍证明**（注销前办理其他事项更方便）
- [ ] **逝者社会保障卡/福利卡**（医保、社保用）
- [ ] **结婚证/婚姻关系证明**（证明配偶关系）

### 继承人相关
- [ ] **各继承人身份证件**（原件 + 复印件）
- [ ] **继承人身份/户籍证明**
- [ ] **亲属关系证明**（户籍证明、结婚证、出生证、机构出具证明、继承文书等）

### 财产凭证
- [ ] **房产证 / 不动产权证**
- [ ] **车辆登记证、行驶证**
- [ ] **银行卡、存折**（建议列出清单：开户行、卡号、余额）
- [ ] **保单**（人寿险、意外险、年金险等）
- [ ] **股票/基金/理财账户信息**
- [ ] **住房储蓄账户/公积金账号**（若当地适用）
- [ ] **企业出资证明、股权证明**（如有）

### 遗嘱与协议
- [ ] **遗嘱**（如有，保留原件）
- [ ] **各类合同、协议**（借款合同、担保合同、租赁合同等）

### 其他
- [ ] **逝者手机**（用于接收验证码，不要过早销号）
- [ ] **逝者重要账号清单**（支付 App、银行 App、邮箱等）
- [ ] **殡葬费用发票/收据**（部分可报销或税前扣除）
- [ ] **借款合同、借条**（涉及债权债务）

## 三、机构联系清单（从地域知识库加载）

> 不要编造电话。所有机构联系方式从地域知识库的"紧急联系方式"章节加载，或通过当地官方查号台、政务热线、官方网站查询。

### 以下各类机构的具体联系方式，请加载 `knowledge/regions/{国家代码}/{地区代码}.md` 获取：

- [ ] **急救**：当地急救电话
- [ ] **报警**：当地报警电话
- [ ] **消防**：当地消防电话
- [ ] **心理援助**：当地心理危机干预热线
- [ ] **政务咨询**：当地政务服务热线

### 医疗与死亡证明
- [ ] **医院 / 当地医疗机构**：开具死亡证明（自然死亡）
- [ ] **法医 / 验尸官办公室**：非正常死亡死亡证明

### 殡葬
- [ ] **殡仪馆**：遗体接运、火化/处置、告别仪式（通过官方渠道查询本地正规殡仪馆）
- [ ] **殡葬主管部门**：殡葬政策咨询、补贴申领、正规机构核实

### 身份与认证
- [ ] **身份/户籍登记机构**：身份/户籍注销
- [ ] **公证处 / 继承认证机构 / 遗嘱认证法院**：继承认证、亲属关系公证、遗嘱认证

### 财产登记
- [ ] **不动产登记机构**：房产过户
- [ ] **车辆登记机构/车管所**：车辆过户

### 社保与福利
- [ ] **社保/养老金经办机构**：养老、医疗、工伤、失业保险
- [ ] **医保经办机构**：医保个人账户结算（部分地方归社保）
- [ ] **住房储蓄账户/公积金管理机构**（若当地适用）
- [ ] **民政/社工部门**：低收入群体丧葬补助

### 金融机构
- [ ] **银行**：存款查询、提取、贷款处理
- [ ] **证券公司/券商**：股票/基金账户继承
- [ ] **保险公司**：商业保险理赔

### 其他
- [ ] **捐献登记机构 / 器官获取组织（OPO）**：器官/遗体捐献
- [ ] **退伍军人事务部门**：退役军人相关事宜
- [ ] **法律援助机构 / 律师协会**：法律咨询、援助申请
- [ ] **金融监管机构 / 消费者保护机构**：金融催收违规投诉
- [ ] **本国驻外使领馆**：海外死亡领事保护

## 四、各地区差异提示

> 各地政策差异较大，以下事项**务必电话确认当地最新要求**，具体见地域知识库。

### 1. 火化 vs 土葬政策
- 各地对火化/土葬的政策差异大：有的强制火化，有的允许土葬，有的视宗教/文化传统而定。
- 具体以当地殡葬法规为准。

### 2. 殡葬补贴标准
- 是否有补贴、标准多少各地不同。
- 部分地区对生态葬（树葬、海葬）有额外补贴。
- 补贴由殡葬主管部门或社保机构发放，标准请电话咨询。

### 3. 身份/户籍注销时限
- 各地要求不同，期限不一。
- 在登记地机构办理，需死亡证明。
- 建议尽早办理，但办前确认其他事项是否需要身份证件。
- 无户籍制度的国家，主要任务是通知死亡登记、注销护照/驾照/选民登记。

### 4. 房产继承是否需认证/公证
- 部分地区试点**直接登记**（无需继承认证/公证）：提交继承材料直接到不动产登记机构办理。
- 多数地区仍要求**继承认证/公证**或**遗嘱认证**。
- 具体以当地不动产登记机构要求为准。

### 5. 小额简化程序
- 若当地有小额简化程序（并非所有地区都有），银行存款门槛金额以下可走简化程序。
- 部分银行网点可能不熟悉该程序，建议先电话咨询开户行。

### 6. 认证/公证收费标准
- 按比例收费或按件收费，各地不同。
- 部分地区对低收入家庭有减免。
- 建议先咨询多家机构比较。

### 7. 跨地区通办覆盖范围
- 户籍、社保、不动产登记等部分地区推进跨地区通办。
- 目前覆盖范围有限，建议通过政务热线或官方平台查询本地是否支持。
- 跨地区通办未覆盖的事项仍需回登记地办理。

### 8. 遗产税/继承税
- 各国差异极大：部分国家有高额遗产税，部分国家无。
- 税率、免税额、申报时限见地域知识库。
- 涉及跨境遗产时税务规划尤为关键。

### 9. 法定继承顺序
- 各法域对法定继承顺序、范围的规定不同。
- 配偶、非婚生子女、养子女、继子女的地位各法域不同。
- 具体见地域知识库。

## 五、常见 10 大坑（全球通用）

1. **死亡证明只开一份，事后不够用**
   - 应对：立即申请多份核证副本（8-10 份以上），多处使用；原件妥善保管。

2. **身份注销前没办其他事**
   - 应对：社保结算、住房储蓄账户提取、银行小额取款等通常在注销前办理更顺，建议先办完再注销。

3. **逝者手机号过早销号**
   - 应对：手机号用于接收银行、App 验证码，办理各类业务前不要销号。**销号前务必先解绑所有服务**。

4. **不办继承认证就想取大额存款**
   - 应对：若有小额简化程序（门槛见地域知识库），门槛以下可简化；超过门槛需继承认证/公证，无捷径。

5. **听信"黑殡仪"中介**
   - 应对：只通过**正规殡仪馆**办理，警惕陌生人主动搭讪推销高价服务；收费可要求出示价目表，通过官方渠道核实资质。

6. **多领养老金/退休金不退还**
   - 应对：逝者养老金/退休金领到去世当月，次月停发；多领的主动退还，否则产生滞纳金甚至涉嫌骗保。

7. **没保留遗嘱原件或见证人不合格**
   - 应对：遗嘱原件妥善保管；见证遗嘱需符合法定资格的见证人（无利害关系人，数量见当地法律），否则可能无效。

8. **急于分割遗产，遗漏债务**
   - 应对：先公告债权人、清查债务，再分割；否则分割后被发现债务，继承人需以已分得遗产清偿。

9. **不咨询律师处理纠纷**
   - 应对：继承纠纷、遗嘱效力、企业债务、涉外继承等，**建议咨询律师**，不要自行处置。

10. **加密货币没告诉家人助记词**
    - 应对：逝者的数字资产（加密货币、数字钱包）需助记词/私钥才能继承；生前未告知的，家属可能永远无法取回。建议生前做好数字遗产清单。

## 我不能替你做的事

- ❌ 不能代办任何签约、申请、取款、过户、销户。
- ❌ 不能代查逝者的银行、社保、公积金、不动产信息。
- ❌ 不能出具法律意见，涉及纠纷请咨询律师。
- ❌ 不能代替官方政策——各地差异大，关键节点务必电话确认。
- ✅ 我能做的：提供清单、流程、风险提示、机构查询指引。

## 使用建议

- 本清单用于整体规划，**不要一次性全部做完**——按时间阶段推进，给自己喘息的时间。
- 遇到具体问题，加载对应分支文件查看详细流程。
- 涉及法律争议、企业债务、涉外继承，**先咨询律师再行动**。
- 累了就歇一歇，事情可以分几天办，不必一天跑完。
- 各地政策差异大，**关键节点务必电话确认当地最新要求**，具体从地域知识库加载。
