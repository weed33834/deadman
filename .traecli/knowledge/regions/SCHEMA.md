# 地域知识库标准格式（SCHEMA）

> 本文件定义地域知识库的标准结构。所有 `regions/{国家}/{地区}.md` 必须遵循此格式。

## 文件命名与目录结构

```
knowledge/regions/
├── SCHEMA.md                    # 本文件
├── {ISO国家代码}/               # 如 CN、US、AU、JP、GB
│   ├── overview.md              # 国家级总览
│   ├── {地区代码}.md            # 州/省/市级，如 CN/beijing.md、US/california.md
│   └── ...
└── ...
```

- 国家代码使用 ISO 3166-1 alpha-2（CN/US/AU/JP/GB/...）
- 地区代码使用国家内通用缩写（如美国州名 california、中国拼音 beijing）
- 若国家内政策高度统一（如新加坡），可仅有 `overview.md`

## 文件结构模板

每个地域知识文件必须包含以下区块。**核心字段**为必填，**扩展字段**按当地实际情况填写，无则标注"本地区不适用"。

## 字段填写规范

1. **未知字段**：写"未知，需用户咨询当地[机构]"，不要留空，不要编造
2. **不适用字段**：写"本地区不适用"
3. **金额**：标注币种和金额范围，如"约 2000-5000 人民币"
4. **时限**：写具体天数，如"30 天内"，不要写"尽快"
5. **政策依据**：尽可能标注法律/法规名称和条文
6. **数据来源**：每个关键信息后标注来源 URL 或官方文件名

## 更新规则

- 每次搜索生成新文件时，必须填写"最后更新"日期
- 超过 6 个月未更新的文件，agent 应提示用户"此信息可能已过时"
- 政策变更高发领域（税务/社保/银行/医疗），建议 3 个月复核一次
