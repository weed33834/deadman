# 中国 - 澳门特别行政区 身后事政策

## 元信息
- 国家: 中华人民共和国（澳门特别行政区）
- 地区: 澳门特别行政区（Macau SAR）
- ISO代码: CN-MO
- 最后更新: 2026-08-08
- 数据来源:
  - 澳门特别行政区政府入口网站 https://www.gov.mo
  - 澳门市政署 https://www.iam.gov.mo
  - 中国政府网 https://www.gov.cn
  - 说明：澳门各部门网站均可从 https://www.gov.mo 「市民」专题进入，本文件不收录易失效的部门子域链接
- 数据可信度: 中（澳门实行葡系大陆法，制度与内地及香港均不同；本文件整理自公开政策知识，办理前务必向对应部门核实）

> **重要提示：澳门是独立法域，实行以《澳门民法典》为核心的葡系大陆法。**《中华人民共和国民法典》继承编**不适用于澳门**。澳门继承制度有三个与内地截然不同的关键点：① **遗嘱原则上必须是公证遗嘱或密封遗嘱**，自己手写的「自书遗嘱」一般不被承认；② 澳门有**特留份（legítima）制度**，遗嘱不得侵害特留份继承人的法定份额；③ 继承须办理**继承权资格证明书**（habilitação de herdeiros），由公证员出具，与内地的「继承权公证」形似而制度不同。

## 紧急联系方式
- 紧急求助（报警 / 消防 / 救护）: 999（澳门另设 110、112 亦可接通紧急台）
- 内地紧急号码在澳门不适用：在澳请拨 999，不要拨 110 内地公安台（澳门 110 为本地紧急台）
- 澳门特区政府综合服务热线、市政署热线、身份证明局热线等: 请从 https://www.gov.mo 首页查询（不编造电话号码）
- 内地居民在澳求助: 中央人民政府驻澳门特别行政区联络办公室；中国公民领事保护与协助全球热线 +86-10-12308
- 情绪支援 / 哀伤辅导: 澳门有社会工作局及多家社会服务机构提供支援，联络方式请从 https://www.gov.mo 查询（不编造电话号码）

## 澳门身后事办理主线（与内地「身后一件事」的差异）

> 澳门**没有**内地式的「身后一件事」跨部门联办，但澳门地域小、部门集中，实务上办理链条较短。

- 主线次序: 取得死亡证明书 → 到**民事登记局**（身份证明局）办理死亡登记 → 办理殡葬（市政署坟场 / 火葬场）→ 办理**继承权资格证明书** → 凭该证明书处理银行、公积金、物业 → 处理债务与税务
- 关键差异 1: 澳门**没有户口本、没有户籍注销**。死亡登记即完成官方记录变更；澳门居民身份证须交回身份证明局
- 关键差异 2: 澳门**已废除遗产及赠与税**（现行涉及的主要为物业移转相关印花税等，请向财政局核实）
- 关键差异 3: 处理遗产的核心文件是**继承权资格证明书**（由公证员出具），而非法院判决；有争议或需清点财产时才走法院**财产清册程序**（inventário）
- 关键差异 4: 澳门的**中央公积金个人账户**（含政府每年注资）是家属最常遗漏的一笔资产
- 来源: https://www.gov.mo （置信度：中）

## 阶段1：死亡证明

### 签发机构
- 医院内死亡（死因明确的自然死亡）: 由医院医生签发死亡证明书（仁伯爵综合医院、镜湖医院、科大医院等）
- 家中或院舍自然死亡: 由曾诊治的医生或卫生局指派的医生到场确认后签发；无法确认死因的，须报警转法医处理
- 非正常死亡（意外、自杀、他杀、死因不明、无医生诊治）: **必须报警 999**，由治安警察局 / 司法警察局到场，转**检察院**指挥，由法医进行尸体检验后出具证明
- 其他情形: 在澳去世的非本地居民（游客、外雇）同样按上述流程办理，并须通知其所属国家 / 地区驻澳领事机构或联络部门

### 所需材料
- 逝者的澳门居民身份证（或护照 / 回乡证 / 其他旅行证件）
- 申报人的身份证明文件
- 医院或卫生局签发的死亡证明书；非正常死亡则为检察院 / 法医的相关文件
- 逝者与申报人的关系证明（如结婚证书、出生证明书等）
- 逝者的病历资料（家中死亡时医生可能要求）

### 流程
1. 判断死亡地点与死因，确定属自然死亡还是须报警转检察院
2. 医院死亡: 由医院开出死亡证明书，并告知领取遗体与后续手续
3. 家中死亡: 先联络主诊医生；无法签发的报警 999
4. 携死亡证明书到**民事登记局**（身份证明局辖下）办理**死亡登记**
5. 领取**死亡登记书面报告 / 死亡证明书叙述证明**（后续银行、继承、保险均须出示）
6. 立即申请多份证明书副本备用

### 时限
- 澳门法律要求在死亡后尽快申报死亡登记（一般为数日内，请以民事登记局最新要求为准）
- 涉及检察院 / 法医检验的个案，登记时间取决于检验进度

### 费用
- 死亡登记本身通常免费；领取证明书副本须缴付法定费用（金额请以民事登记局最新公布为准，本文件不编造金额）

### 当地特殊规定
- 澳门的死亡证明文件与内地《居民死亡医学证明（推断）书》不是同一文件，两地互认须办理公证认证
- 涉及检察院的个案，家属不得自行安排殡葬，须待检察院批准发还遗体
- 澳门文件常同时具中葡文版本；在内地或海外使用时留意是否须翻译认证
- 来源: https://www.gov.mo （置信度：中）

## 阶段2：遗体处理

### 遗体安置选项
- 医院殓房: 医院内死亡时短期存放，超期收费（请以医院最新公示为准）
- 法医部门 / 殓房: 须检验的个案由检察院指定存放，家属不得自行领走
- 殡仪馆: 澳门有本地殡仪服务机构提供设灵、出殡服务
- 家中暂存: 澳门居住环境密集，实务上不可行

### 殡葬方式
- 火葬: 澳门以火葬为主流。火葬场由**市政署**管理，须预约火化时段
- 土葬: 澳门坟场墓地极为紧张。市政署管理的公众坟场墓穴一般为**有限期租用**，期满须续期或起掘拾骨改置骨灰龛，家属须留意期限通知
- 骨灰安置: 市政署骨灰楼 / 骨灰龛位须申请，供应紧张；亦有教会与私营骨灰安置设施
- 生态葬: 澳门推行**海上撒灰**与**纪念花园撒灰**，由市政署安排，须提出申请
- 其他: 天主教、佛教、道教等宗教团体设有各自坟场与仪式安排

### 时限要求
- 领取遗体与出殡时间取决于火葬场 / 坟场预约情况
- 涉及检察院检验的个案，须待批准发还遗体后方可殓葬

### 费用参考
- 市政署管理的火化、墓穴、骨灰龛位等收费属法定收费，标准公开（金额请以市政署最新公示为准，本文件不编造金额）
- 殡仪服务（灵堂、棺木、仪式、花牌等）属市场价，家属有权比较多家服务商

### 殡葬补贴/丧葬费
- **社会保障基金（FSS）丧葬津贴**：受益人身故的，其家属或负责殓葬者可向社会保障基金申请丧葬津贴（金额由行政法规订定并会调整，**请向社会保障基金核实，本文件不编造数字**）
- **社会工作局经济援助**：经济困难家庭的殓葬费用可向社会工作局申请援助
- **工作意外（工伤）致死**：依澳门劳动法例，雇主 / 保险公司须承担殓葬费用及死亡赔偿，须向劳工事务局申报
- 申请方式: 凭死亡证明文件、殓葬开支单据、申请人身份及关系证明，向对应部门申请

### 当地特殊规定
- 澳门墓穴与骨灰龛位供应紧张，期满续期通知务必留意，逾期可能被起掘
- 遗体 / 骨灰运返内地或运往海外：须办理防腐证明、死亡证明等文件并办理出入境手续，建议委托有跨境经验的殡仪服务商
- 器官捐赠: 澳门可通过卫生局登记捐赠意愿，死亡后由医院与家属沟通
- 来源: https://www.iam.gov.mo （置信度：中）

## 阶段3：身份注销

### 注销机构
- 民事登记局（死亡登记即完成官方记录变更）
- 身份证明局（交回澳门居民身份证）

### 所需材料
- 死亡登记证明书 / 死亡证明书叙述证明
- 逝者的澳门居民身份证
- 逝者的澳门特区护照 / 旅行证 / 回乡证等（如有）
- 办理人身份证明及与逝者的关系证明

### 流程
1. 完成死亡登记
2. 将逝者的澳门居民身份证交回身份证明局注销
3. 将澳门特区护照、旅行证等交回身份证明局
4. 回乡证（港澳居民来往内地通行证）交回受理机构注销
5. 通知其他持有逝者记录的部门（交通事务局、财政局、社会保障基金、房屋局等）

### 时限
- 澳门没有内地式「30 天内销户」的统一法定时限，但应尽快办理，避免身份被冒用
- 财政局须获通知，以处理逝者的职业税等税务事宜

### 异地办理
- 逝者在境外去世的，须先取得当地死亡证明并办理认证，再回澳办理死亡登记
- 澳门地域小，各部门集中于半岛与氹仔，实务办理往返成本低

### 注销前必须完成的事项
- 死亡证明书多申请几份副本（每家银行、保险公司均要收取）
- 清点逝者名下的银行账户、保险单、中央公积金账户、证券账户、物业、车辆
- 通知业主委员会 / 管理公司；如属**社会房屋 / 经济房屋**须尽快通知房屋局，涉及承租权与转名
- 通知雇主 / 生意伙伴
- 停止自动过账、信用卡自动扣款

### 当地特殊规定
- **社会房屋承租人去世**是澳门的紧急事项：同住家庭成员须尽快向房屋局申请承租权转移，逾期或不符资格可能须迁出
- **经济房屋**转让受法律限制（禁售期、优先回购等），继承同样受限
- 逝者若为公司股东 / 行政管理机关成员，须向商业及动产登记局办理变更
- 澳门没有「户口本」，亲属关系须以出生证明书、结婚证书等民事登记文件证明
- 来源: https://www.gov.mo （置信度：中）

## 阶段4：数字账号处理

### 主要平台的逝者通道
- 澳门本地电讯商: 携死亡证明与身份证明到门市办理终止服务或过户；先解除所有自动扣账
- 银行 App / 网上银行: 银行获悉持有人身故后会**冻结账户**；家属不得再使用逝者的网上银行、提款卡，须凭继承权资格证明书办理（见阶段5）
- 澳门通（Macau Pass）/ 聚易用、MPay 等电子钱包: 储值余额属遗产，须联络营运商按其身故账户流程处理
- 内地平台（微信支付、支付宝）: 澳门居民若持有内地账户，其内地资产须按内地流程办理（微信 95017、支付宝 95188）
- Apple ID / Google 账号: 可申请「逝者账户」处理，上传死亡证明
- 社交媒体（Facebook / Instagram / WhatsApp / 微信）: 账号本身不可继承，可申请注销或转为纪念账户
- 「澳门公共服务一户通」: 澳门政务数字身份，应在死亡登记后注销，避免身份冒用

### 当地特殊规定
- 《澳门民法典》对「数字遗产」无专门条文；按财产一般原则，账号内的**财产性权益属遗产**，账号本身通常不可继承
- 未办妥继承手续前擅自动用逝者账户，可能涉及刑事责任，切勿因「知道密码」而自行操作
- 澳门与内地、香港三地账户并存的情形常见，须分别按三地程序办理

## 阶段5：金融资产继承

> **澳门处理遗产的核心文件是《继承权资格证明书》（habilitação de herdeiros）**，由**公证员**（公证署或私人公证员）出具，确认谁是合法继承人及其份额。银行、登记局、保险公司均以此为凭。

### 银行存款
- 小额简化程序: 部分银行对小额存款设有简化处理，但**澳门没有内地式统一的「5 万元免公证」法定门槛**；能否简化由各银行按其内部规定决定，须逐家询问
- 一般程序: 办理**继承权资格证明书** → 凭该证明书及死亡证明、继承人身份证明到银行办理提取或转账；金额较大或继承人众多的，银行可能要求补充**财产清册**（inventário）程序的结果
- 查询逝者账户途径:
  - 逐家银行发函查询（澳门没有统一的跨行查询通道）
  - 从逝者的信件、报税记录、自动过账记录追溯
  - 有争议时可循法院财产清册程序，由法院命令披露
- 联名账户: 联名账户的权属须查阅开户合约条款，不能一概认为自动归生存者所有

### 证券/股票
- 继承流程: 凭继承权资格证明书向证券行 / 银行的证券部门办理过户或卖出
- 逝者持有的内地 A 股、香港股票，须分别按内地、香港的程序办理

### 保险
- 社会保险: 转阶段8（社会保障基金养老金、丧葬津贴、中央公积金）
- 商业保险理赔: 人寿保单**有指定受益人的，保险金一般不属遗产**，受益人可直接向保险公司索偿；未指定受益人的归入遗产，须凭继承权资格证明书办理
- 保单查询: 澳门没有统一的保单查询平台，须逐家保险公司查询；澳门金融管理局可提供获准经营的保险公司名单

### 当地特殊规定
- **澳门已废除遗产及赠与税**（现行涉及的主要为物业移转印花税等，请向财政局核实最新税务安排）
- 继承权资格证明书由公证员出具，程序相对法院程序简便快捷，是澳门实务主流
- **有下列情形之一的，通常须走法院「财产清册」（inventário）程序**：继承人之间有争议、有未成年或无行为能力继承人、须清点债务、需要正式分割
- **跨境资产**：逝者在内地、香港或海外的资产，须另在该地办理继承程序；澳门的继承权资格证明书在内地不能直接使用，须办理公证认证

## 阶段6：不动产与车辆

### 房产过户
- 路径:
  - 办理**继承权资格证明书** → 到**物业登记局**办理不动产的继承登记（登记于继承人名下）
  - 继承人之间有争议或须正式分割的，走法院**财产清册程序**，凭法院判决办理登记
- 所需材料:
  - 物业登记证明（房地产登记局的登记书面报告）
  - 死亡证明文件
  - 继承权资格证明书
  - 继承人身份证明
  - 遗嘱（如有，须为公证遗嘱或密封遗嘱）
  - 财政局的物业税缴纳记录
  - 银行按揭文件（如有）
- 涉税:
  - **无遗产税**（澳门已废除遗产及赠与税）
  - 继承取得不动产的登记与相关印花税安排，请向**财政局**核实最新规定
  - 逝者名下的物业税（房屋税）欠款须清缴
- 特殊:
  - **经济房屋 / 社会房屋**：受法律限制，继承与转让须符合房屋局的资格条件与禁售期规定
  - **未解除按揭的物业**：须先与银行处理按揭
  - **夫妻财产制**：澳门有取得共同财产制、分别财产制、一般共同财产制等，**夫妻财产制直接决定哪些财产属遗产**，须先查阅结婚登记记载的财产制度（这是澳门与内地的重大差异，切勿默认「一半归配偶」）
  - **特留份**：即使有遗嘱，也不得侵害特留份继承人的法定份额（见阶段7）
- 来源: https://www.gov.mo （置信度：中）

### 车辆过户
- 流程:
  1. 办理继承权资格证明书
  2. 到**交通事务局**办理车辆所有权移转登记
  3. 提交文件、缴付费用、办理车辆查验（如需要）
  4. 领取新的车辆登记证明
  5. 重新投保（原车主保险随身故失效，无有效保险驾驶属违法）
- 所需材料:
  - 车辆所有权登记证明
  - 死亡证明文件
  - 继承权资格证明书
  - 继承人身份证明
  - 有效验车证明（如适用）
  - 有效第三者责任保险
- 澳门特殊:
  - 澳门**没有内地式的车牌指标摇号**；车牌号码属登记事项，转让规则请向交通事务局确认
  - 澳门车位与车辆均属遗产，车位买卖须同步办理物业登记
  - 澳门与内地、香港的车辆牌照互不通用；跨境车（澳车北上等）另有专门规定

### 当地特殊规定
- 逝者名下车辆完成过户前不应继续行驶，保险与登记状态均有问题
- 停车场月租、自动缴费服务须及时终止

## 阶段7：遗产继承整体

> **《中华人民共和国民法典》继承编不适用于澳门。** 以下为《澳门民法典》继承编（第五卷）的制度要点。**具体条文号与份额比例以现行《澳门民法典》文本为准，办理前务必向公证员或律师核实。**

### 法定继承顺序
- 依据《澳门民法典》继承编
- 法定继承人的召集顺序（大陆法系的「顺位」概念，前一顺位存在时后一顺位不获召集）：
  1. **配偶及直系血亲卑亲属**（子女、孙子女……）
  2. **配偶及直系血亲尊亲属**（父母、祖父母……）
  3. **兄弟姊妹及其直系血亲卑亲属**
  4. **四亲等内的其他旁系血亲**
  5. **与死者有事实婚关系之人**（须符合法定要件）
  6. **澳门特别行政区**
- **重大差异**：澳门的配偶在**第一及第二顺位均与血亲共同继承**，且配偶的应得份额有法定下限保障；这与内地「配偶、子女、父母平均分配」的规则不同
- **先决问题——夫妻财产制**：分配遗产前须先按夫妻财产制**清算夫妻共同财产**，确定哪一部分才是逝者的遗产。澳门有取得共同财产制、一般共同财产制、分别财产制等，**不同财产制结果差别极大**

### 特留份（legítima）——澳门与内地最重要的差异之一
- 澳门采**特留份制度**：配偶、直系血亲卑亲属、直系血亲尊亲属为**特留份继承人**，法律为其保留遗产的一定比例，**立遗嘱人不得以遗嘱剥夺或减少**
- 侵害特留份的遗嘱处分，特留份继承人可提起**减扣之诉**予以缩减
- 可自由处分的部分称为「可处分部分」（quota disponível），只有这部分才能按遗嘱自由分配
- 内地《民法典》只有「必留份」（为缺乏劳动能力又无生活来源的继承人保留必要份额），保护范围与力度与澳门的特留份**完全不同**
- 具体的特留份比例视继承人组合而定，**请务必向公证员或律师确认，本文件不列举比例以免误导**

### 遗嘱形式
- 依据《澳门民法典》，遗嘱的**普通形式只有两种**：
  - **公证遗嘱**（testamento público）：由公证员按法定程序作成并存档
  - **密封遗嘱**（testamento cerrado）：由立遗嘱人书写或认可后签署，再送交公证员作成核准书
- **关键陷阱：澳门原则上不承认自己手写、无公证程序的「自书遗嘱」**，也不承认内地式的**代书遗嘱、打印遗嘱、录音录像遗嘱、口头遗嘱**（仅在极特殊情形有特别形式遗嘱）
- 因此，内地居民按内地方式立下的自书遗嘱，**在处分澳门财产时可能无效**；在澳门有财产的，应另立符合澳门法律形式的遗嘱
- 遗嘱可随时撤回或变更；以最后一份有效遗嘱为准

### 继承公证/法院程序
- 澳门的核心程序是**继承权资格证明书**（habilitação de herdeiros）
  - 办理机构：公证署或私人公证员
  - 流程: 准备死亡证明、亲属关系的民事登记证明、遗嘱查询结果 → 继承人（或部分继承人加证人）到公证员前作出声明 → 公证员作成证明书
  - 时间与费用：相对法院程序快捷；费用按公证收费表计（请向公证署核实）
- **法院财产清册程序（inventário）**：用于清点、分割遗产，适用于继承人有争议、有未成年 / 无行为能力继承人、须清偿债务并正式分割等情形
- 遗嘱查询：可向公证署查询逝者是否曾立公证遗嘱或密封遗嘱（这是澳门实务的必备一步，切勿遗漏）
- 继承纠纷处理路径：协商 → 公证程序无法解决的转法院财产清册程序 → 提起继承之诉
- 法律援助：符合条件的可申请司法援助（法律援助），向法院申请

### 遗产税
- **澳门已废除遗产及赠与税**
- 与遗产相关的其他税项：物业移转的印花税、逝者的职业税 / 所得补充税结清、物业税（房屋税）欠款等，请向**财政局**核实
- 澳门每年发放的**现金分享**：受益人身故后的处理须向对应部门查询，不可继续代领

### 无人继承遗产处理
- 无任何法定继承人且无有效遗嘱的，遗产归**澳门特别行政区**所有

### 当地特殊规定
- **继承的接受与抛弃**：澳门法律允许继承人**接受**（可为单纯接受或「以财产清册方式接受」）或**抛弃**继承，且有法定期间与程序。以财产清册方式接受的，继承人仅在所得遗产范围内负责债务——这是保护自己的重要工具，务必咨询公证员或律师
- 夫妻财产制是澳门继承的先决问题，办理前必先查明
- 内地公民继承澳门遗产：内地出具的亲属关系公证书须办理**澳门转递**（由中国委托公证人办理），流程较长
- 澳门居民在内地、香港有资产的，须分别按三地程序办理，建议委托熟悉三地法律的律师统筹

## 阶段8：社保与福利结算

> 澳门的社会保障制度由**社会保障基金（FSS）** 与**中央公积金制度**两层构成，与内地的「五险一金」结构完全不同（澳门**没有住房公积金**、**没有医保个人账户**）。

### 社会保险结算
- 养老/退休金:
  - **社会保障基金养老金**：受益人身故后须立即通知社会保障基金停止发放；**多领的款项须退还**
  - **中央公积金个人账户**：这是澳门的重要资产。账户内包括政府每年注资的「启动款项」与「预算盈余特别分配」，以及雇主 / 雇员供款（如参加非强制性中央公积金）。持有人身故后，账户结余由**受益人 / 继承人**申领，须向社会保障基金提出申请
  - **公务员退休及抚恤制度**：公务员遗属可能享有抚恤金 / 遗属金，须向退休基金会查询
- 医疗:
  - 澳门**没有医保个人账户**。卫生局对澳门居民提供免费或资助的初级卫生保健与特定人群免费医疗
  - **医疗补贴计划（医疗券）**：持有人身故后未使用的医疗券不可转让、不可继承，须停止使用
- 其他（工作意外 / 失业）:
  - **工作意外（工伤）致死**：依澳门劳动法例，由雇主的强制保险支付殓葬费与死亡赔偿，须向劳工事务局申报；赔偿计算方式由法例订明（**金额请向劳工事务局核实**）
  - **社会工作局经济援助**：经济困难家庭可申请援助金，受助人身故须通知停止发放

### 丧葬补助与抚恤金
- 适用对象: 社会保障基金受益人的家属或负责殓葬者（丧葬津贴）；工作意外致死者家属（雇主保险）；公务员遗属（抚恤金）；经济困难家庭（社会工作局）
- 标准: 由行政法规或劳动法例订明并会调整（**金额请向社会保障基金、劳工事务局、退休基金会核实，本文件不编造数字**）
- 申请方式: 凭死亡证明文件、殓葬开支单据、申请人身份及关系证明，向对应部门申请；须留意各计划的申请期限

### 公积金/养老金账户
- 澳门**没有住房公积金**
- **中央公积金个人账户**是最接近的对应物，也是家属最常遗漏的一笔资产。持有人可通过「一户通」或向社会保障基金查询账户结余
- 身故后的账户处理：由社会保障基金按其规定发放给受益人 / 继承人，须提交死亡证明与继承权资格证明书等文件

### 当地特殊规定
- 中央公积金账户务必查询，切勿遗漏
- 领取养老金、残疾金、社会工作局援助金的逝者，家属须尽快通知停止发放，多领须退还
- **澳门与内地社保不能互相转移**；在两地都工作过的须分别办理
- 澳门居民在内地参保（如「澳人内地参保」政策下）的权益，须回内地按内地程序办理
- 来源: https://www.gov.mo （置信度：中）

## 阶段9：债权债务

### 法律原则
- 依据《澳门民法典》继承编：遗产须先清偿逝者的债务与遗产管理费用，剩余部分才分配给继承人
- 继承人可选择：
  - **单纯接受继承**：可能须以自身财产承担超出遗产的债务（风险高）
  - **以财产清册方式接受继承**：仅在所得遗产范围内负责债务（**这是保护自己的关键选择**）
  - **抛弃继承**：不取得遗产，亦不负清偿责任
- **这与内地「继承人以所得遗产实际价值为限清偿」的当然限定责任不同**：在澳门，是否限定责任取决于继承人**如何接受继承**，务必咨询公证员或律师后再作决定
- 债务清偿顺序：殓葬及遗产管理的合理费用 → 有担保的债权 → 其他债权 → 遗赠 → 继承人分配
- 债权的时效期间依《澳门民法典》规定（一般债权与特别债权时效不同），须咨询律师

### 常见债务处理
- 按揭（房贷）: 通知银行；可由继承人继续供款（须银行同意），或出售物业清偿。部分按揭附有人寿保险，应先查证
- 信用卡: 通知发卡银行持卡人身故并提供死亡证明；由遗产清偿，家属个人不当然代偿；附属卡须停止使用
- 其他:
  - 私人贷款、财务公司贷款：由遗产清偿
  - **博彩相关债务**：澳门博彩业发达，逝者可能有博彩信贷（「码佣」「叠码」）等债务，此类债务的法律效力与追讨须特别谨慎，务必咨询律师，切勿轻易签署任何还款承诺
  - 担保 / 保证责任：逝者曾为他人担保的，责任随遗产转移
  - 税务欠款：职业税、所得补充税、物业税欠款须清缴，向财政局办理
  - 管理费、水电费：须结清，欠费影响物业登记
  - 公司债务：逝者为无限公司股东或独资经营者的，须特别注意个人责任范围

### 当地特殊规定
- **在决定接受继承前，先清查债务**：一旦单纯接受，可能须以自身财产还债
- **不要以个人名义签署任何「承诺还款」文件**
- 遇到滋扰、恐吓式催收，立即报警 999
- 澳门法律对高利贷有规管，涉及赌博借贷的高息债务尤须咨询律师
- 澳门有金融管理局辖下的信用资料库，查询逝者信贷记录须提交继承权资格证明书等文件

## 特殊情形

### 异地/跨国死亡
- **澳门居民在内地去世**:
  - 死亡证明由内地医疗机构或公安机关签发
  - 该内地文件在澳门使用，须经**中国委托公证人**公证并办理**澳门转递**
  - 遗体 / 骨灰运返澳门：须办理内地出境与澳门入境手续，建议委托有跨境经验的殡仪服务商
  - 澳门的死亡登记：凭经转递的内地死亡证明向民事登记局办理（具体要求请向民事登记局核实）
  - 澳门居民身份证仍须交回身份证明局；澳门的银行、中央公积金、物业仍须按澳门程序办理
- **内地居民在澳门去世**:
  - 按澳门流程办理死亡登记，取得澳门死亡证明文件
  - 该文件在内地使用，须办理公证与认证 / 转递手续
  - 遗体 / 骨灰运返内地须符合内地入境与殡葬管理要求
  - 逝者在内地的户籍注销、社保结算、遗产继承，仍须回内地按内地程序办理
- **澳门 — 香港 — 内地三地资产**: 三地为三个独立法域，遗产须**分别在三地办理**；澳门的继承权资格证明书在香港、内地均不能直接使用
- **在海外去世**: 联络中国驻当地使领馆（24 小时领事保护热线 +86-10-12308）；取得当地死亡证明并办理认证；澳门资产按澳门程序办理

### 非正常死亡
- 必须报警 999，由治安警察局 / 司法警察局到场
- 由**检察院**指挥调查，法医进行尸体检验；家属须待检察院批准方可领回遗体殓葬
- 工作意外致死须同时向**劳工事务局**申报，并通知雇主的强制保险公司
- 涉及刑事案件的，民事赔偿与继承程序可能须待刑事程序进展
- 交通事故、工作意外的赔偿与遗产继承是**两条独立的线**，赔偿协议签署前建议先咨询律师

### 器官/遗体捐献
- 器官捐赠: 澳门居民可通过卫生局表达捐赠意愿；死亡后由医院与家属沟通，联络方式请从 https://www.gov.mo 查询（不编造电话号码）
- 遗体捐献: 用于医学教育的遗体捐赠须生前登记并取得家属同意，接收单位与流程请向卫生局或相关院校查询
- 时间窗口: 器官捐赠须在死亡后极短时间内完成；遗体捐赠须尽快通知接收单位

### 其他当地特殊情形
- **失踪与死亡宣告**: 依《澳门民法典》，长期下落不明的可先经**推定失踪**程序管理其财产，其后符合条件的可申请**推定死亡**；具体期间与程序请咨询律师（澳门的期间与内地《民法典》的 2 年 / 4 年规定不同）
- **未成年子女的亲权与监护**: 依《澳门民法典》家庭法编，父母一方去世的由另一方行使亲权；父母双亡的由法院指定监护人
- **外地雇员（外雇）在澳去世**: 须同时通知劳工事务局、治安警察局出入境事务厅及其所属国家 / 地区的领事机构；遗体运返原籍的手续由家属或雇主与殡仪服务商办理
- **博彩业从业人员**: 澳门博彩企业普遍设有团体保险与员工福利，家属应向逝者所属企业的人力资源部门查询
- **跨境家庭**: 澳门与内地跨境婚姻普遍，内地配偶 / 子女的继承权受澳门法律保障，但亲属关系证明须经公证转递

## 医疗政策补充（medical-guide 团队使用）

> 本区块供 medical-guide 团队使用。澳门**没有社会医疗保险制度**，采「政府提供 + 高度资助」模式，与内地医保体系完全不同。

### 医保体系概览
- 医保类型: 澳门**没有医保**。公共卫生服务由**卫生局**提供，包括各区卫生中心（初级卫生保健）与仁伯爵综合医院（山顶医院）
- 参保方式: 无须参保。澳门居民享有免费的初级卫生保健；**特定人群**（如孕产妇、10 岁以下儿童、65 岁以上长者、学生、癌症病人、传染病病人、精神病病人、囚犯、公务员及其家属等）享有**免费专科与住院医疗**
- 报销基本原则: 无「报销」概念。符合免费资格的直接免费；不符合的按公立医疗收费表缴费（远低于成本），非本地居民按较高标准收费

### 门诊特殊病种/慢性病备案
- 澳门无「门诊特殊病种备案」制度
- 慢性病由卫生中心与山顶医院专科跟进；癌症、精神病、传染病等病人属**免费医疗对象**，无须另行备案报销

### 异地就医
- 澳门无「异地就医备案」制度
- **跨境医疗安排**：澳门与内地（尤其横琴、珠海）有医疗合作与转诊安排，覆盖范围会调整，请从 https://www.gov.mo 查询最新政策
- 卫生局对确需外送治疗（澳门无法诊治）的病人设有**外地就医**安排，须经专科医生评估与卫生局批准

### 大病保险/补充保险
- 澳门无公营大病保险
- 重大疾病的治疗费用由公共卫生系统承担（符合免费医疗资格者）或自费 / 商业保险
- 商业医疗保险须自行投保，澳门保险市场受**澳门金融管理局**监管

### 商业保险理赔通用流程
- 理赔申请渠道: 保险公司客户服务、保险代理 / 经纪
- 所需材料: 保单、死亡证明文件、受益人身份证明、关系证明、医院证明；意外身故须附警方报告
- 时限: 依保单条款与《澳门商法典》保险相关规定，务必尽快通知保险公司
- 争议处理: 可向**澳门金融管理局**投诉，或循法院诉讼；亦可申请消费争议仲裁（视性质而定）

### 医疗纠纷处理
- 院内投诉渠道: 医院的病人服务 / 投诉部门
- 行政投诉渠道: **卫生局**（对公立与私立医疗机构均有监管职能）
- 专业操守投诉: 澳门设有医疗人员专业委员会体系，对医生等医疗人员的专业操守进行规管
- **医疗事故法律制度**：澳门已就医疗事故的鉴定与赔偿建立专门制度，设有医疗事故鉴定委员会，具体程序请向卫生局查询
- 诉讼: 医疗损害赔偿属民事诉讼，建议咨询律师

### 临终关怀/安宁疗护
- 机构查询渠道: 卫生局辖下医院与社会服务机构提供纾缓治疗与临终关怀服务，可从 https://www.gov.mo 查询
- 居家临终支持: 由卫生中心与社会服务机构提供家居照护支援，覆盖范围有限
- 医保覆盖情况: 符合免费医疗资格者可免费接受公立系统的纾缓治疗

### 当地特殊医疗规定
- **非本地居民在澳就医费用较高**：内地访客、游客在澳就医按非本地居民收费标准缴费，欠费属遗产债务
- 澳门医疗记录索取：家属须凭死亡证明与继承权资格证明书向医院申请
- 澳门公私营医疗并存，私家医疗（如镜湖医院部分服务、科大医院）收费由机构订定
- 来源: https://www.gov.mo （置信度：中）
